### Steps

1. In `tests/test_tags_store.py`, delete the line `raise unittest.SkipTest("bundle: enabled by ticket 001")` and change nothing else in that file.
2. Import `re` and `NotFoundError, ValidationError` from `.domain`. Add `_TAG_RE = re.compile(r"^[a-z0-9][a-z0-9-]{0,31}$")`.
3. `normalize_tags(raw)`: if `raw` is not a `list`, raise `ValidationError(INVALID_TAGS_MESSAGE)`. For each element: if not `isinstance(element, str)`, raise `ValidationError`; `tag = element.strip().lower()`; if `_TAG_RE.fullmatch(tag)` is None (this rejects empty, too long, leading `-`, spaces, `_` and non-ASCII), raise `ValidationError`. Collect into a set; if more than `MAX_TAGS` distinct tags remain, raise `ValidationError`. Return `sorted(tags)`.
4. `TagStore.set_tags(note_id, raw)`: `tags = normalize_tags(raw)` first (validation before the note lookup); then `self._require_note(note_id)`; then `DELETE FROM note_tags WHERE note_id = ?`, `INSERT INTO note_tags (note_id, tag) VALUES (?, ?)` for each tag (`executemany`), `self.conn.commit()`; return `tags`. Never touch the `notes` table.
5. Add a private helper `_require_note(note_id)`: `SELECT 1 FROM notes WHERE id = ?`; no row -> raise `NotFoundError(f"note {note_id} not found")`.
6. `get_tags(note_id)`: `self._require_note(note_id)`; return `[row[0] for row in conn.execute("SELECT tag FROM note_tags WHERE note_id = ? ORDER BY tag", ...)]`.
7. `note_ids_with_tag(tag)`: `SELECT note_id FROM note_tags WHERE tag = ?` with `tag.strip().lower()`; return a `set` of ints (empty set when none; never raise for odd input).
8. `delete_tags(note_id)`: `DELETE FROM note_tags WHERE note_id = ?` and commit; no error when nothing is deleted.
9. Run `sh .bundle/check-frozen.sh && PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests` from the repository root and make it pass. Commit.
